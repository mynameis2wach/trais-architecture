# TRAIS — TRanscription, AI assisted Search

**Fully local RAG pipeline** for meeting audio processing —
transcription, speaker identification, summarization, and
natural language retrieval over accumulated meeting history.

## Features

- Audio Transcription — Local speech-to-text with speaker diarization
- Voice Signatures — Automatic speaker identification via stored voice embeddings
- Meeting Summarization — Full-meeting summary vectors alongside chunk-level embeddings
- Natural Language Retrieval — Plain text queries, no command syntax required
