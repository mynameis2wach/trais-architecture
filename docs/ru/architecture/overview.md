# TRAIS — TRanscription, AI assisted Search

**Полностью локальный RAG-пайплайн** для обработки аудиозаписей встреч —
транскрипция, идентификация спикеров, суммаризация и
поиск на естественном языке по накопленной истории встреч.

## Возможности

- **Транскрипция аудио** — локальное распознавание речи с диаризацией спикеров.
- **Голосовые подписи** — автоматическая идентификация спикеров по сохранённым голосовым эмбеддингам.
- **Суммаризация встреч** — векторы полного саммари встречи хранятся вместе с эмбеддингами чанков.
- **Поиск на естественном языке** — запросы обычным текстом, не требующие командного синтаксиса.
